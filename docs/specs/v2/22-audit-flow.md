## The progress-event contract

From `apps/web/lib/v2/progress.ts`: the events the pipeline will stream while a check runs. Each also carries `at_ms`, milliseconds since the check started; events arrive in time order. The reducer there turns them into the state the crawl screen draws, and `toProgress` maps any state onto the CC-11 `Progress` snapshot, carrying the last 3 fetches without identity or timing, which that snapshot does not hold.

| Event             | Fields                                                                                                                                                                                                                                                                                                                                                                                     | What it says                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `stage`           | phase: robots_and_sitemap / homepage / crawl / crawler_tests / without_js / grading; state: now / done                                                                                                                                                                                                                                                                                     | A step of the check starts (`now`) or finishes (`done`), in the contract's order.                                           |
| `pages_estimated` | pages: number                                                                                                                                                                                                                                                                                                                                                                              | The engine's estimate of the site's size, from the sitemap and the homepage: the "about N".                                 |
| `page_fetched`    | url: string; identity: string; purpose: crawl / test / control / render; status: number; ms: number; links: number                                                                                                                                                                                                                                                                         | One request and its answer: who we said we were, why, the status, how long it took, and the internal links in the response. |
| `page_linked`     | url: string; from: string; via: link / javascript                                                                                                                                                                                                                                                                                                                                          | The first link to a page was found, on another page; a JavaScript link is found by rendering. Places the page on the map.   |
| `page_classified` | url: string; as: orphan / js_only                                                                                                                                                                                                                                                                                                                                                          | Known once the crawl is complete: no link reaches the page, or only JavaScript does.                                        |
