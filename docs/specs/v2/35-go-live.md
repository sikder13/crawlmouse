# CC-35 — go live: the production crawl worker, the go-live check, a reversible switch-on

Owner decision, 2026-11-13: there is no beta. v2 goes live for everyone as soon as it is ready, one
flag at a time. This step makes that a checked, ordered, reversible procedure. It adds no customer
feature, changes no grade, switches no flag, sets no variable and dispatches no workflow.

## What differed from the brief, measured on `dfa3ec37`

- The worker's `/healthz` answers `{"ok":true}` and names no release
  (`packages/worker/src/server.ts:274`). The deploy labels the image with the commit SHA, and the go-live
  check reads the label through Fly's Machines API with a read-only token.
- The Stripe prices are the lookup keys of `CATALOG` (`apps/web/lib/billing/catalog.ts`), whose amounts
  come from `apps/web/lib/billing/prices.ts`.
- Inngest's API needs the environment's signing key to say whether the app is synced; the sync is a box
  the owner ticks.
