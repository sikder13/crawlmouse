A read-only API today; the audit as a tool your agent can call, next.

Every Pro account can create a read-only key and pull the latest audit of any of its sites as JSON: grades, the crawler table, fixes with packets, the link map as an edge list. The write side — start an audit, mark a fix done, re-check — and an MCP server, a CLI and a GitHub check are being built. This page says what exists now and what does not.
