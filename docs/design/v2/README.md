# Crawlmouse v2 design source

The locked v2 screens (33 artboards, rendered HTML) and the shared stylesheet they were built from, kept in the repo so build steps can read them directly.

- `screens/*.dc.html` — one file per locked screen; open in a browser. Layouts are locked; numbers and copy marked as engine-derived are regenerated by the engine (see `FACTS-proposed.md`).
- `base.css` — the shared tokens and components the screens use. The brand font and mark are **not** taken from this file: the live site's `apps/web/lib/fonts.ts` (Fraunces display, Geist body, Geist Mono) and `components/icons/CrawlmouseMark.tsx` with the `crawl` + orange `mouse` wordmark are the standing brand and override the typeface named here.
- `DESIGN-LOCK-v1.md` — the design rules, the lock record and the seven rules every screen follows.
- `FACTS-proposed.md` — the facts file every screen's numbers and copy come from; entries marked ENGINE-DERIVED wait for the engine.

Check the screen count: `ls docs/design/v2/screens | wc -l` prints 33.
