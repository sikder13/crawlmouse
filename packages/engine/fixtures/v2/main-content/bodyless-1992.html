Hypertext Project - Overview

The project joins document retrieval and hypertext into one system that a reader can use without training.

Documents live on many servers. A reader follows a link from one to the next without needing to know where either is kept, and an index can be searched as if it were another document.

Reading

A browser shows each document with its links marked. Choosing a link fetches the document it names, using a simple protocol that any server can answer.

Writing

Authors write documents in a plain markup that any editor can produce, and add links by naming the document they point to.
